2. Finalidad del sitio web

Este sitio web se ha desarrollado como parte de un Trabajo de Fin de Máster, con fines exclusivamente académicos y demostrativos. Su objetivo es mostrar conocimientos técnicos y de desarrollo, sin que exista prestación de servicios reales a terceros ni tratamiento de datos personales con fines comerciales.

3. Recogida de datos personales

En este sitio web no se recogen, almacenan ni tratan datos personales de ningún tipo. No se dispone de formularios de contacto, registros de usuario, boletines de suscripción ni ningún otro mecanismo destinado a la obtención de información identificable de los visitantes.

4. Uso de cookies y tecnologías similares

Este sitio web no utiliza cookies propias ni de terceros, ni ninguna otra tecnología similar destinada al seguimiento, análisis de comportamiento, elaboración de perfiles o medición de audiencia.

5. Registros de acceso y logs

No se realiza, por parte del autor, ningún tratamiento activo de registros de acceso (logs) con fines de analítica, marketing, elaboración de perfiles o similares. Cualquier registro técnico que pudiera generarse de forma automática por la infraestructura de alojamiento se limita a los estrictamente necesarios para el funcionamiento básico del servicio y la seguridad técnica, sin que el autor los utilice para identificar a los usuarios.

6. Enlaces externos

Este sitio puede contener enlaces a recursos externos, como por ejemplo el repositorio de código en GitHub. El acceso a dichos enlaces se realiza bajo la responsabilidad del usuario. El autor no controla ni es responsable de las políticas de privacidad o condiciones de uso de los sitios de terceros.
